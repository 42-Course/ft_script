NAME

script_options - Configuration options for the script command.

 

SYNOPSIS


#include <ft_script.h>  

Data Fields


const char * output_file

const char * command

int append_mode

int quiet_mode

int return_exit_status

int flush_mode
 

Detailed Description

Configuration options for the script command.

This structure holds all command-line options and their state. It encapsulates configuration to make it easy to pass around and test.

Ownership: Created on stack in main(), passed by pointer to functions Lifetime: Exists for entire program execution  

Field Documentation

 

int script_options::append_mode

Append mode flag (-a option)
•
0: truncate existing file (default)
•
1: append to existing file

 

const char* script_options::command

Command to execute (for -c option)
•
NULL: run interactive shell
•
Non-NULL: execute this command Ownership: Points to argv string, do NOT free

 

int script_options::flush_mode

Flush output after each write (-f option)
•
0: use buffered output (default)
•
1: flush after each write

Note: This is a BONUS feature. When enabled, fflush() is called after each write to the output file, ensuring real-time updates. This is useful for monitoring scripts in progress but has a performance impact.  

const char* script_options::output_file

Output file path
•
NULL: use DEFAULT_TYPESCRIPT
•
Non-NULL: caller-provided filename Ownership: Points to argv string, do NOT free

 

int script_options::quiet_mode

Quiet mode flag (-q option)
•
0: print start/done messages (default)
•
1: suppress messages

 

int script_options::return_exit_status

Return child exit status (-e option)
•
0: always exit with 0 (default)
•
1: exit with child's exit status
