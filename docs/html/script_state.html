NAME

script_state - Runtime state of the script session.

 

SYNOPSIS


#include <ft_script.h>  

Data Fields


int master_fd

int output_fd

pid_t child_pid

int child_status

struct termios original_termios

Detailed Description

Runtime state of the script session.

This structure holds all the runtime state needed for the I/O loop. Separating state from options makes the design cleaner and easier to test.

Ownership: Created on stack or heap, cleaned up explicitly Lifetime: From PTY creation to child process termination  

Field Documentation

 

pid_t script_state::child_pid

Child process ID
•
Used to wait for child and get exit status
•
Set by fork(), used by wait()

 

int script_state::child_status

Child exit status
•
Raw status from wait()
•
Use WIFEXITED/WEXITSTATUS/WIFSIGNALED to interpret

 

int script_state::master_fd

PTY master file descriptor
•
Used by parent to communicate with child
•
Must be closed when session ends Ownership: We own this, must close it

 

struct termios script_state::original_termios

Original terminal attributes (stdin)
•
Saved at start, restored at end
•
Required to put terminal into raw mode and restore it Ownership: We own this data

 

int script_state::output_fd

Output file descriptor (typescript file)
•
Where we log the session output
•
Must be closed when session ends Ownership: We own this, must close it

 

int script_state::terminal_modified

Flag indicating if terminal is in raw mode
•
0: normal mode
•
1: raw mode (must restore on exit)
